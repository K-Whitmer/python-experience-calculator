# python-experience-calculator
Overview
This is a beginner Python project designed to calculate cumulative professional work experience based on user input.
This program allows users to enter years of experience, including decimal values and calculates the total experience provided.

Features
 - Accepts numerical user input
 - Supports decimal values using float()
 - Calculates cumulative experience.
 - Uses input validation to handle invalid entries.
 - Uses exception handling to prevent the program from crashing when incorrect input is entered.

Technologies Used
 - Python 3
 - Visual Studio Code
 - Windows 11
 - Python built-in functions and exception handling

Future improvements
 - Allow users to enter experience from multiple jobs
 - Calculate total experience automatically
 - Improve input validation
 - Add a graphical user interface.
